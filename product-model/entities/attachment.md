# Attachment

A file or pasted image added to a meeting for reference.

## Information kept

- **Name** — The original display name.
- **Content** — The locally saved file.
- **Size** — File size.
- **Kind** — Image, PDF, text or another file type.
- **Added** — When it was attached and its recording position when applicable.
- **Extracted text** — Available local text for search and AI context.
- **Text availability** — Whether PDF text could be extracted.
