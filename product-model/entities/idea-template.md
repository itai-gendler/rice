# Idea template

A built-in or custom instruction for suggestions during a meeting.

## Information kept

- **Title** — The template name.
- **Description** — The purpose of the suggestions.
- **Instruction** — What the AI should suggest.
- **Categories** — Optional named output categories.
- **Built in** — Whether the template ships with Rice.
- **Customized** — Whether the built-in content has a local override.
