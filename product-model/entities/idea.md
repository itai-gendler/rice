# Idea

A suggested idea, question or risk from a live meeting cycle.

## Information kept

- **Text** — The suggestion.
- **Time** — When it was produced.
- **Category** — The idea type and optional template category.
- **Template** — The template used at generation time.

## States

### Suggested

Available for the person to consider.

### Pinned

Copied into the person’s annotations.

### Dismissed

Hidden from the live suggestion list.
